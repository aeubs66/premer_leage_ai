# Security

This is a local research application. Keep `.env`, API tokens, database credentials, local-state backups, and private datasets out of issues and commits. The repository intentionally ignores local secrets and runtime state.

If you find a security problem in a hosted copy of this repository, use GitHub's private vulnerability reporting feature when it is enabled. For a local installation, update the affected dependency or code, rotate any exposed credential, and rebuild from a trusted checkout. Never include a live token in a report.
