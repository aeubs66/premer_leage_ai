# Reproducibility and local-state audit

Git is the source of truth for code, tests, configuration defaults, dependency lockfiles, database migrations, compact provenance, and research methodology. Machine-specific state stays local.

## Git and secret audit

- `.env.example` contains safe blanks and the LIGHT profile; it has no machine-specific path. Bootstrap copies it only when `.env` is absent.
- `.env`, `.env.*`, tokens, database credentials, and local URL overrides are ignored. Safe `.env.example` files remain tracked through explicit ignore exceptions.
- The tracked history was inspected for secrets and oversized binaries. It contains the project specification, source, docs, tests, config, and lockfiles. No downloaded CSVs, SQLite files, model binaries, MLflow runs, reports, logs, dependency trees, caches, or virtual environments are tracked. No history rewrite was needed.
- Download sidecars are locally ignored with data. Their non-secret provider, season, source URL, checksum, record count, schema version, and retrieval time are recorded in [`dataset-manifest.json`](dataset-manifest.json). Trained model provenance and measured metrics are in [`model-manifests`](model-manifests/).

## Important ignored files

| Item | Classification | Recovery |
| --- | --- | --- |
| `.env`, API tokens, database credentials | **SECRET** | Copy `.env.example`; set local values. Never commit secrets. |
| `.venv/` | REGENERATABLE | `scripts/bootstrap.ps1` or `uv sync --locked` |
| `frontend/node_modules/` | REGENERATABLE | `npm ci --prefix frontend` |
| `frontend/.next/`, `*.tsbuildinfo`, Python caches | REGENERATABLE | Regenerated by frontend/Python tools. |
| `data/raw/` | REGENERATABLE SOURCE CACHE | `football-ai update-data`; source and checksum for the measured run are in the tracked dataset manifest. |
| `data/processed/*.jsonl` | REGENERATABLE | `football-ai update-data`; each snapshot is content addressed. |
| `data/processed/features-*.csv` | REGENERATABLE | `football-ai update-data` rebuilds the shared feature cache. |
| `data/football.db` | **NON-REGENERABLE LOCAL STATE** | Results and features can be reimported, but saved predictions and attached results require a private database backup. |
| `models/`, `models/champion.json` | OPTIONAL ARTIFACT | `football-ai train`; exact artifacts are local and are not committed. |
| `reports/` | OPTIONAL ARTIFACT | `football-ai evaluate` and `football-ai backtest`. |
| `mlruns/` | OPTIONAL ARTIFACT | Training recreates local tracking; artifact paths point to the machine where a run was recorded. |
| `logs/`, `work/`, `tmp/` | TEMPORARY | Recreated by tools as needed. An older unused frontend dependency backup is preserved under `work/node_modules_previous`; it is ignored and excluded from repository changes. |

## Fresh PC

```powershell
git clone <private-repository-url>
cd premer_leage_ai
.\scripts\bootstrap.ps1
```

Use `-Train` to opt into model fitting or `-SkipData` to avoid downloading. If the provider is unavailable, import data with `football-ai update-data --csv PATH --season YYYY/YYYY`. The trained model metrics included with the repository describe a previously measured artifact; that binary itself is not part of a fresh clone.
